# Data Entry Workflow and Quality Checks

## Before entry
- Read the source and project rules.
- Confirm permitted abbreviations, date formats, numeric formats, and treatment of missing values.
- Identify mandatory fields and unique identifiers.

## During entry
- Enter one source record per spreadsheet row unless instructions specify otherwise.
- Keep each value in the correct column.
- Preserve punctuation and meaningful formatting when required.
- Do not infer illegible or missing information; flag it for review.

## Quality checks
- **Completeness:** check required fields for blanks.
- **Accuracy:** compare entries against the original source.
- **Consistency:** apply the same formatting rules throughout.
- **Duplicates:** check IDs and other approved matching fields.
- **Validity:** verify dates, numeric values, and allowed categories.
- **Traceability:** record the source reference and log corrections.

## Completion note
Record the number of records reviewed, issues found, corrections made, and items escalated only when those figures were actually counted.
