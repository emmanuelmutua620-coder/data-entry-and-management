# Data Entry and Management

This repository demonstrates a careful workflow for entering, organizing, validating, and quality-checking structured data.

## Contents
- `templates/data-entry-template.csv` — blank column structure for a dataset you are allowed to publish.
- `templates/qa-log-template.csv` — issue and correction log.
- `templates/data-management-and-qa-template.xlsx` — Excel workbook with Data Entry, QA Log, and Read Me sheets, dropdowns, and preformatted rows.
- `examples/fictional-data-demo.csv` — invented training records. These are not real people or client data.
- `docs/data-dictionary.md` — explanation of each field.
- `docs/workflow-and-quality-checks.md` — recommended process.
- `case-study/CASE-STUDY.md` — report template for your own completed project.

## Recommended workflow
1. Confirm the task instructions, source, format, and permission to use the data.
2. Create a copy of the blank template and preserve the original source.
3. Enter one record per row and keep fields in their correct columns.
4. Standardize only where the rules allow; do not guess missing values.
5. Check required fields, duplicates, formats, and totals.
6. Log uncertain records and corrections for review.
7. Save a clean, authorized sample and document what you did.

## Important
Do not upload personal data, client records, or employer datasets unless you have explicit permission. Use synthetic data for public demonstrations.
