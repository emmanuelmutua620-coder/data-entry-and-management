# Data Dictionary

| Field | Description | Example / rule |
|---|---|---|
| Record ID | Unique identifier for each row | `DEMO-001`; do not reuse IDs |
| First Name | Given name, only where authorized | Synthetic names in demos |
| Last Name | Family name, only where authorized | Synthetic names in demos |
| County | County or region label | Use a consistent spelling |
| Record Type | Category of record | Use agreed project categories |
| Date Received | Date source was received | Use `YYYY-MM-DD` |
| Status | Processing stage | Not started / In progress / Ready for QA / Approved / Needs correction |
| Source Reference | Safe reference to the source | Avoid public links to restricted files |
| Notes | Relevant processing note | Do not add unnecessary personal information |

Change these fields to match the actual project instructions. The dictionary must describe the dataset you really submit.
